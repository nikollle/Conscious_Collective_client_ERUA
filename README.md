# Conscious Collective

A sustainability-focused mobile app for ethical fashion choices.
Built with React Native + Expo for the ERUA project.

## Stack
- Expo + Expo Router (file-based routing)
- NativeWind (Tailwind for React Native)
- React Query + Axios (data fetching)
- TypeScript

## Setup
\`\`\`bash
npm install
npx expo start
\`\`\`
Then scan the QR with Expo Go on your phone.

## Folder structure
- `src/app/` – screens (Expo Router routes)
- `src/components/` – reusable UI
- `src/lib/` – api client, helpers
- `src/data/` – mock JSON for development
- `src/types/` – TypeScript types
